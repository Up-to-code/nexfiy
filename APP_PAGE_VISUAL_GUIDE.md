```

**Hover State:**
```

└─────────────────┘
```

**Pressed State:**
```
┌─────────────────┐
│ App Store       │ (Slight inward effect)
└─────────────────┘
```

**Normal:**
```

```

```

## Color Palette

### Button Colors
- **App Store (iOS)**: Black (#000000)
- **Google Play**: Green (#10B981)
- **Web App**: Blue (primary)
- **macOS**: Gray (#374151)

### Text Colors
- **Headings**: text-foreground (dark)
- **Body**: text-foreground/70 (lighter)
- **Hints**: text-foreground/60 (very light)
- **Links**: text-foreground with hover:text-blue-600

### Background Colors
- **Header**: Gradient (app-specific, e.g., red to orange)
- **Sections**: Alternating between background and secondary/20
- **Cards**: background with border-border
- **Hover**: shadow-md

## Accessibility Features Shown

### Screen Reader Text (Hidden)
```html
<span className="sr-only">
  App Store Link
  Opens App Store in new window
</span>
```

### Focus States
- All interactive elements show clear focus ring
- Tab order is logical (top to bottom, left to right)
- No focus traps

### Keyboard Navigation
- All buttons clickable with Enter
- All links accessible with Tab
- Can navigate entire page with keyboard alone

## Spacing & Layout

### Section Padding
- Top: `py-16 md:py-24` or `py-20 md:py-32`
- Sides: `px-4 md:px-6`
- Container: `max-w-3xl md:max-w-4xl mx-auto`

### Card Padding
- Inside: `p-6 md:p-8`
- Border: `border border-border`
- Gap: `gap-6 md:gap-8`

### Grid Layouts
- Mobile: 1 column
- Tablet: 2 columns (`grid-cols-1 md:grid-cols-2`)
- Desktop: 3-4 columns (`grid-cols-1 md:grid-cols-3 lg:grid-cols-4`)
